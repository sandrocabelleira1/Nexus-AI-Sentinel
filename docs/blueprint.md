# **App Name**: Nexus AI Sentinel

## Core Features:

- AI Predictive Analysis Core: The AI continuously monitors global data (geopolitics, nature, tech, markets) to predict impacts on user assets and provide a causal explanation tool.
- User Portfolio Management: Users can manually add and manage their financial assets and their storage locations (e.g., Binance, Ledger, XP) securely, without sharing banking credentials.
- Personalized Dashboard: A dashboard displaying a summary of the 'World Mood', hot alerts, and a visual overview of asset risk.
- AI Insight Display: Presents detailed AI-generated alerts, causal explanations from the predictive tool, market signals, and risk analysis. Supports both 'Essential' (simplified) and 'Full' (technical) display modes.
- Interactive AI Assistant: A floating AI consultant tool, fully aware of the user's portfolio, providing real-time tailored guidance and analysis via a chat interface.
- Display Mode Switching: Allows users to toggle between 'Essential' and 'Full' modes for financial explanations, adapting content for different levels of expertise.
- Firestore Data Persistence: Securely stores user-registered assets, preferences, and personalized configurations within a Firestore database.

## Style Guidelines:

- Primary Color: A vibrant blue (#73B2FF) chosen for its association with technology and clarity, standing out against a dark theme. (HSL: 225, 70%, 65%)
- Background Color: A very dark, subtle cool gray-blue (#121315) derived from the primary hue, providing a sophisticated 'slate-950' foundation for the 'Dark Tech Modern' aesthetic. (HSL: 225, 15%, 8%)
- Accent Color: A bright violet (#705CF5) selected to provide a 'neon purple' contrast, visually enhancing interactive elements and highlights in an analogous yet distinct manner. (HSL: 250, 70%, 60%)
- Headline font: 'Space Grotesk' (sans-serif) for its modern, tech-savvy, and scientific feel. Body font: 'Inter' (sans-serif) for its neutral, objective readability suitable for longer text blocks.
- Utilize geometric, clean, and potentially line-based icons. Asset cards should feature risk-indicative icons that dynamically 'glow' in green, orange, or red. The floating assistant icon should embody a discreet, intelligent 'consultant' aesthetic.
- The dashboard should be clean and spacious, presenting 'World Mood' and alerts in an organized hierarchy. Asset cards will feature rounded borders. The chat interface for the AI assistant will be subtly integrated as a floating element, ensuring it's always accessible yet unobtrusive.
- Implement subtle glow effects on interactive elements and risk icons on asset cards, reflecting their status. Employ smooth transitions for state changes and data updates to enhance the modern and predictive feel of the application.
